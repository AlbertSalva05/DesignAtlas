Submit a resource

Every submission is reviewed by hand before it's listed. An entry is accepted when it has:

  1. A public source page. Nothing behind a login just to read what it is.
  2. A named creator. A person, studio or organisation we can credit.
  3. Stated terms of use. A licence or pricing page that says what's allowed.
  4. Something new. Not already in the index under another name.

An index for people who make interfaces.

Design Atlas collects UI kits, design systems, icons, typefaces, tools and learning material in one place, for designers, students and the developers who build what they draw.

It doesn't host files or take a cut. Each entry is a short, checked description that points to the creator's own page, with the licence stated up front so you know what you can do before you click.
